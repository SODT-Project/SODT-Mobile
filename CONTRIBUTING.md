# Contributing to SODT Mobile

Thanks for your interest in improving SODT Mobile! Contributions of all sizes are welcome.

## Getting started

1. Fork the repository and create a branch for your change.
2. Open the project in Android Studio with a compatible Android SDK, or use the Gradle wrapper from the repository root.
3. Make a focused change and add or update tests when appropriate.

## Build and test

Run the unit tests and build the debug app from the repository root:

```sh
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

## Open a pull request

Describe what changed and why, include the tests you ran, and link any related issue. For user-interface changes, include screenshots when useful. Please keep pull requests focused and avoid including unrelated formatting changes.

## Report an issue

When opening an issue, include the steps to reproduce the problem and relevant Android version and device details. Remove passwords, server keys, private files, and other sensitive information from logs or screenshots before sharing them.
